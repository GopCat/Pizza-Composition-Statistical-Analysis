# Pizza Composition Statistical Analysis (R)
## Overview
Statistical analysis project investigating whether pizza manufacturers can be identified based on ingredient composition data.

## Objectives

- Explore dataset characteristics and detect outliers
- Reduce dimensionality using Principal Component Analysis (PCA)
- Classify samples using statistical models
- Compare classification performance

## Methods

- Data preprocessing & outlier removal
- Principal Component Analysis (PCA)
- Linear Discriminant Analysis (LDA)
- Quadratic Discriminant Analysis (QDA)
- Logistic Regression

## Results
All classification models achieved high prediction accuracy, confirming significant compositional differences between manufacturers.

## Technologies
- R
- Statistical modeling
- Multivariate analysis
